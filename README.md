# 丹宸录 · 奏折模拟器

一款以架空明清朝代为背景的纯前端奏折批阅游戏。无需安装依赖，打开 `index.html` 即可游玩，也可直接托管到 GitHub Pages。

## 游戏内容

- 每日收到来自不同衙门和地区的奏折。
- 正式题本与御前密折拥有不同封皮、流转程序和情报可信度。
- 奏折之间存在日期、账目、证词矛盾，官员也会互相攻讦。
- 支持“阅”“知道了”“核议”“督查”及自定义朱批。
- 包含架空舆图、驿路流向、官员关系网、党派影响和案情脉络。
- 奏折支持启封、合折与连续折页动画。

## 本地运行

直接打开 `index.html`，或在此目录运行任意静态文件服务器。例如：

```sh
python -m http.server 8765
```

随后访问 `http://127.0.0.1:8765/`。

## 存档说明

当前为单机网页游戏。每位玩家的数据仅保存在自己的浏览器中，玩家之间不会共享进度。
